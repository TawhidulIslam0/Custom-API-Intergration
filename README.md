# Custom API Integration: SAP S/4HANA to Zetheta FinSight

## Project Overview
This repository contains the design, specification, and proof-of-concept implementation for a production-grade integration between Meridian Manufacturing’s SAP S/4HANA ERP system and Zetheta FinSight, a financial analytics platform. Built as part of Zetheta's FDE-9B project (Custom API Integration).
