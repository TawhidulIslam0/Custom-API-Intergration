# Integration Data Mappings (FDE-9B)

## Overview
This directory contains the field-level transformation mappings bridging SAP S/4HANA source structures (`SRC-001` through `SRC-012`) to Zetheta FinSight destination payloads (`DST-001` through `DST-012`).

## Structure
* Financial Mappings: GL, AP, AR, Cost Centres, Profit Centres, Material Ledger
* Operational Mappings: Purchase Orders, Sales Orders, Fixed Assets, Bank Statements, Budget/Actual, Inventory
